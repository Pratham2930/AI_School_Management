Training data format

Download the CSV template. Use one student-term row per observation and include the approved outcomes for that same student-term.

Required columns: student_id, attendance_percentage, average_marks, final_percentage, pass_fail

Optional numeric features: previous_average_marks, assignment_completion_percentage, standard, term_number

Percent fields must be from 0–100. Pass/fail accepts pass or fail. Include at least 50 records from at least 30 distinct students, with at least 5 distinct students in each outcome. Student IDs are used only to keep each student's records together during evaluation; IDs and names are never model features.

Protect student data: upload only data you are authorized to use. Do not include names, addresses, contact details, or other unnecessary personal data. Features must have been known before the final outcome; do not use future or outcome-derived values as predictors. CSV contents stay on this server and are not placed in Kafka messages. The raw CSV is removed after successful training.

Queue a training run

Use an authorized CSV or import a read-only Google Sheet. A running Kafka broker and the separate model-training worker are required. If Kafka is unavailable, validated data is retained privately for retry.

Import from Google Sheets

The server reads the selected range using a configured service account. Share the sheet with that account as a Viewer.
