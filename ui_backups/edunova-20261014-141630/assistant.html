Local model setup
Install and start Ollama, then download the configured model with ollama pull {{ ollama_model }}. Set OLLAMA_MODEL to another installed model if needed. The app connects to OLLAMA_BASE_URL (default http://127.0.0.1:11434). Your message and a fresh role-scoped set of relevant school facts are sent to that Ollama server. Students only receive their own academic details; parents only receive details for linked children; teacher context is limited to assigned classes; administrators receive aggregate school facts. Chat history stays in this browser and is not saved by the app. Use a trusted local endpoint. The assistant provides guidance only; use the relevant forms to make official school record changes.
