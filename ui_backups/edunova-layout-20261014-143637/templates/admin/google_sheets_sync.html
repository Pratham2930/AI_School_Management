Create a preview

Use a Google service account with Viewer access. The sheet must have one header row, no duplicate IDs, and only the documented columns. Preview data is stored privately for review; absent sheet rows never delete school records.

Recommended sheet headers

Admissions (required): admission_number, name, current_standard, division, academic_year, previous_percentage, guardian_name, guardian_relationship

Admissions (optional): stream, date_of_birth (YYYY-MM-DD), gender, phone, email, address, previous_school, previous_standard, admission_fee, guardian_phone, guardian_email

Teachers: employee_id, name, email, phone; optional: qualification. New teacher accounts use the employee ID as username and receive a generated temporary password via configured email/SMS.

Staff: employee_id, name, position; optional: phone, active.

Each batch is limited to 2,000 rows. Existing records match by admission_number or employee_id. Approval upserts only supplied optional values; it does not delete records absent from the sheet or overwrite fee/payment status.
