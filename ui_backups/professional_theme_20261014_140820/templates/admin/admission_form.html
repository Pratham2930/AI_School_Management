Senior Secondary Stream Required

Select Science, Commerce or Arts. Division allocation will happen only inside the selected stream.

Automatic Division Allocation

The system checks the student's previous percentage, current standard, division rules and available capacity.

For Standards 11 and 12, the system also checks the selected stream before allocating the division.

If the ideal division is full, the closest available division in the same standard and stream will automatically be selected.

Parent / Guardian Information

Enter the parent or guardian information. If the same parent already exists, the system will link this student to the existing parent account.

Parent Account & Login

Parent login credentials are not generated immediately when this form is submitted.

First, the admission will be saved with Pending Payment status.

After the admission fee is received and confirmed by the administrator, the system will generate the Student ID and Parent login credentials.

If this parent already has an account, the new student will automatically be linked to the existing Parent account.
